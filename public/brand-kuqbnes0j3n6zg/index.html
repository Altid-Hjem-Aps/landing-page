Brand book·03

A calm base. One highlight

Altid Hjem looks the same everywhere: Cream and Deep forest, two typefaces, rounded corners, warm Danish. On every screen and in every mail one element is allowed to stand out.

Each sheet shows the rule first, then real examples. The pill on an example tells you where it comes from.

Brand book·04

The whole household's finances in one app

Altid Hjem brings the household's fixed costs together in one place: food, electricity, insurance and economy. One overview, one login.

Brand book·05

Keep the base. Highlight one element

All media uses Cream, Deep forest and the same UI elements. One big number, one colour block or one Deep forest background may stand out. Never two.

Always the same

  • The colours and what they mean
  • DM Sans and Onest, one type scale
  • Rounded corners: 20 px in the app, 32 to 50 in mails
  • Buttons, cards and the tab bar
  • Warm, plain Danish

Free to vary

  • Scale: a number as big as the screen allows
  • Pastel blocks and Deep forest backgrounds
  • Data shown as a picture, not as a table
  • One element people remember
Brand book·06

Would you screenshot it?

Our design philosophy is built around this. We don’t prioritise what’s conventional, polished or perfectly aligned. Instead, we focus on creating unique, memorable experiences that make users want to take a screenshot and share it with a friend.

Brand book·22

The app is our picture

We don’t use stock photos or standalone illustrations. When displaying the app, we also use real app screens with sample data, shown in a phone, and can include elements breaking out of the phone.

  • Real screens, never mock-ups with filler text
  • The number is always readable in the picture
  • Icons come from the app, each in a pastel circle with a white ring
Brand book·23

Six checks for every screen

  1. 1

    Picture first

    Start with the picture. Use text only where the picture cannot explain the idea.

  2. 2

    Make them want it

    The standard is “I want that.” Correct is not enough.

  3. 3

    Show what they miss

    A feature that is switched off is shown as a missed saving in kroner. Never greyed out.

  4. 4

    See it, not read it

    An error looks like an error before anyone has read a word.

  5. 5

    Within thumb reach

    The button or switch sits where the thumb can reach it.

  6. 6

    Nothing extra

    Remove back arrows with no function, lines that repeat the title, and pills with no purpose.
